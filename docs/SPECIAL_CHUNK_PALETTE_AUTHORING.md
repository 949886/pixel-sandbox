# SpecialChunk Bottom Palette Authoring

The World Layout Editor provides a TileMap-like bottom palette for the independent
`ChunkLayer`. The palette is an authoring tool only: `ChunkLayer` continues to store
only fixed `SpecialChunkDef` placements, while ordinary chunks are generated by the
Piece system at runtime.

## Opening the palette

1. Open a `WorldLayout` through the **World Layout** dock.
2. Select the `ChunkLayer` node, or press **Fixed Chunks** in the World Layout toolbar.
3. The transient **Special Chunks** bottom dock opens automatically.
4. Select a thumbnail to make it the current brush. The editor switches to Paint mode.
5. Click a world cell to place the selected fixed SpecialChunk.

The top toolbar keeps Select, Paint, Erase, and Pick. The bottom panel owns brush
selection, search, filters, previews, and resource inspection.

## Data source

Palette content comes only from:

```gdscript
ChunkLayer.palette_chunks: Array[SpecialChunkDef]
```

The editor does not scan directories and does not infer resources from paths. Add a
new `SpecialChunkDef` to the `palette_chunks` array of the relevant WorldLayout when
it should be available to designers.

## Search

The search box matches, case-insensitively:

- `display_name`
- content `id`
- `allowed_biomes`
- semantic `tags`

Search and tag filters are combined.

## Tag filters

Tags are authored directly on each `SpecialChunkDef`:

```gdscript
@export var tags: Array[StringName]
```

The **Tags** menu supports multiple checked tags. When more than one tag is selected:

- **Match any** shows chunks containing at least one selected tag.
- **Match all** shows only chunks containing every selected tag.

Use small, reusable semantic tags. Recommended examples:

```text
surface, ground, entrance, spawn
mine, snow, deep
reward, treasure, shrine
large, ruins, grotto
```

Do not encode resource names, file paths, or one-off editor rules as tags.

## Brush synchronization

- Selecting a palette item chooses the brush and enters Paint mode.
- The Pick tool selects the SpecialChunk under the cursor and reveals it in the
  palette. Filters are cleared only when they hide the picked chunk.
- Double-clicking a palette item, or pressing **Inspect**, opens its
  `SpecialChunkDef` in the Inspector.
- The footer shows the current brush, footprint, and tags.

## Preview authoring

Each `SpecialChunkDef` may provide:

- `editor_preview`: thumbnail/art preview
- `editor_color`: complete footprint backing color
- `display_name`: readable palette label
- `size_in_chunks`: authored footprint

The World Layout overlay always draws a complete `editor_color` footprint before the
transparent preview. Therefore preview images may preserve transparent air without
making the authored Chunk appear incomplete.

## Runtime boundary

The palette does not instantiate TileMap scene tiles and does not generate runtime
chunks. Its output is only:

```text
ChunkPaintPlacementDef
  -> origin
  -> SpecialChunkDef
```

`SpecialChunkPlanner` reserves these authored footprints before random special chunks
and procedural Piece generation.
